# b24cloud

> Infraestructura en cloud y self-hosted. Consultoría en IA y automatización para pymes + SaaS verticales.

## Qué hacemos

- **Consultoría** — Automatización con IA y n8n para pymes.
- **Vollery** — SaaS multi-tenant para clubes de raqueta (reservas, monedero, academia).
- **Pulsari** — Seguimiento de obra en tiempo real para propietarios y constructoras.
- **Infra global** — Proxy, logging, monitoring y secrets sobre Docker + Oracle Cloud + Tailscale.

## Stack

- **Docker Compose + Infisical + GitHub Actions** — Despliegue remoto por SSH
- **Cloudflare** — Workers, Tunnel, DNS
- **Keycloak (OIDC)** — Identidad central
- **Grafana Loki + Fluent Bit** — Observabilidad
